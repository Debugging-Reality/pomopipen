# PomoPipen

A personal desktop Pomodoro timer for study sessions.

This project is based on [Pomotroid](https://github.com/Splode/pomotroid) by Splode, with added features and UI improvements. Among the additions, finished focus sessions can optionally be synced one way to a dedicated Google Calendar that the app creates.

See [PRIVACY.md](PRIVACY.md) for how data is handled.
