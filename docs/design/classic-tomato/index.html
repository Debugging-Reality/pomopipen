经典番茄Classic Tomato

一张暖纸色的农产品标签，中间放一件可操作的拟真番茄计时物件。两种计时器外观——A 机械番茄钟、B 鲜番茄环——共用同一套版式、文字、控件、计时状态与信息层级；切换外观不暂停、不重置当前计时。

静态外观稿画面按真实尺寸 1:1 绘制，用于审阅外观与层级；静止画面不证明动效成立。
浏览器几何原型本页内用分层素材实时绘制，可拖动、可播放，用来验证“哪一部分在转、往哪边转、何时停”。
待实现验证需在应用内按真实计时事件实测（刷新率、缩放、减少动态、窗口尺寸）。

本页只是设计包：原型脚本仅服务于评审，不是应用实现代码。物件图像是从参考图 23、03 抠出的评审占位，正式资产需重新拍摄、渲染或取得授权（见 §6）。

02运动构造与分镜A：只转刻度鼓的印刷层 · B：果实静止，环按时间消耗

2.1 A 的分层与固定 / 转动部件 浏览器几何原型

关键判断：刻度鼓的鼓身是绕竖轴旋转对称的光滑塑料，旋转时鼓身像素本身看不出变化，能看出转动的只有印在上面的刻度。因此不需要虚构照片背面：鼓身作为一张不印刻度的静态底图，刻度作为矢量层按圆柱投影实时绘制——两侧按 cos θ 压缩、越过 ±90° 被遮挡；高光层固定在刻度之上。上盖、绿蒂、白三角指针、横向接缝全部固定。

物件按素材坐标 1:1 绘制（470 × 384，放在框内 (60, 60)）。紫色为标注，不属于界面。状态：12:30 运行中（T = 25）。

2.2 时间如何映射到转角

映射规则（数字化机械隐喻，不是 60 分钟发条）
一圈= 本轮设定时长 T。刻度数值沿计时方向递减，结束时 0 到达固定指针。
位置刻度值 v 的转角 θ(v) = 360° × (r − v) / T，r 为剩余分钟；θ = 0 即正对指针，θ > 0 在指针右侧。
运行方向剩余时间减少时，鼓面自右向左经过指针（俯视顺时针）；每秒推进 360° / (60·T)，25 分钟时 0.24°/秒。
起点 / 终点待开始时 r = T，“0 / T”同在接缝位；下方读数 25:00 区分“满”与“零”。完成时 r = 0，0 回到指针。
可见性只绘制 cos θ > 0.05 的正面；θ 越靠两侧越压缩、越淡；背面不绘制。
主刻度步长从 1 / 2 / 3 / 5 / 10 / 15 / 20 / 30 中取最小且使主刻度数 ≤ 6 的步长；若最后一个主刻度离 0 不足 0.4 步，则省略它。
细刻度取 步长/10、/5、/2 中第一个使总数 ≤ 60 的值；细刻度只是视觉分格，不承诺“一格一分钟”。

2.3 A 分镜：待开始 → 运行 → 暂停 → 完成 静态外观稿由原型逐帧绘制

2.4 A 调时交互：拖拧与数字输入 静态外观稿

只在待开始状态可调。左右拖动刻度带即“扭转”，不要求用户在透视曲面上画圆；每 1 分钟一格棘齿吸附。拖动中刻度淡到 35 %，新时长只以读数为准；松手后刻度按新 T 重排，鼓面回到接缝。点击读数可直接输入，二者等价。范围沿用现有 1–90 分钟。运行后拖拽无效。

5.1 色板（建议设计值，非原图取样）

使用规则
  • 纸色与留白约 75 %，红色主体及动作约 15 %，墨色与绿蓝约 10 %（构图倾向，不逐屏凑比例）。

5.6 周历：每个科目是一种番茄 静态外观稿

按你给的课表参考：周历里的时间块做成番茄——圆润的果身、顶上一簇萼片或一根带叶果柄。不同科目用不同番茄品种区分：大红、黄、黑紫、绿斑马、粉、橙、靛蓝、青。品种靠颜色 + 皮纹 + 顶部形态三重区分，每块都写科目或任务名，所以色觉障碍用户也分得清。果身上下边缘严格对应开始与结束时间，萼片只是装饰。

八个番茄品种 = 科目候选色（固定顺序，CVD 校验通过）
时间块构造：三种常见长度（1 小时 = 54 px）
  • 果身 = 时间：上边缘 = 开始，下边缘 = 结束；圆角 = min(14, 高/2)，所以 25 分钟块是一颗樱桃小番茄，90 分钟块是长圆的罗马番茄。
  • 萼片最多向上探出 3 px；前后两块只隔 5 分钟（约 4.5 px）也不会压到上一块。
  • 果柄 + 单叶向上探出 6 px（短块）或 9 px（≥ 40 px 的块），只在上方空隙足够时出现，否则自动换成萼片（周一 14:00 第二轮“政治”即是此例）。
  • 皮纹只画在果身左右两侧约 18 %、向中间渐隐，中间写字区保持纯色；字色按对比度取深墨或暖白，均 ≥ 4.5 : 1。
  • 高度 < 38 px 只显示名称；≥ 38 px 加开始时间；最小高度沿用现有 18 px。点击选中：藏蓝外环 + 下方详情条。
  • 未归类科目：纸影色果身 + 深墨虚线轮廓。用户自定义的非品种颜色：保留番茄外形与萼片，不加皮纹，历史颜色不自动改写。
  • 这是“不用番茄形图表”原则的唯一例外（按你的新要求）：只用于周历时间块；折线、柱状、环形图仍是普通图表。

5.7 一键换成最接近的番茄品种 静态外观稿映射由本页按规则实算

已有科目的颜色不会被自动改写。在经典番茄主题下，如果还有科目不是品种色，“设置 → 科目”顶部出现一行提示和按钮；点开后先预览每个科目会换成哪个品种，确认后才改，改完可以撤销。

规则
出现条件当前主题是经典番茄，且至少 1 个科目（含已归档）的颜色不在 8 个品种色里。全部是品种色时整行消失。
“最接近”在 OKLab 色彩空间里算距离，明度差只按 0.4 倍计入：品种色明度固定，人判断“像不像”主要看色相。不按 RGB 数值比较。
不撞色已经是品种色的科目先占住自己的品种；其余科目求总色差最小的一一配对（不是逐个抢最近的，否则蓝色可能被挤到绿色）。科目多于空余品种时，多出来的取最接近品种并在预览里注明“与其他科目同色”。
预览每行：旧颜色 → 番茄小图 + 品种名；可逐行取消勾选。按钮写明数量“换 N 个科目”。
影响范围颜色存在科目上，所以周历、统计里这些科目的历史记录也会一起换色；学习记录本身不变。预览底部写明这一点。
撤销应用后底部提示“已把 N 个科目换成番茄品种 · 撤销”，10 秒内可一键恢复原颜色；之后也能在单个科目里手动改回。
不做不在切换主题时自动执行；不改归档状态和科目顺序；其他主题下不显示这行。
